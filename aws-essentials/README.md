## 📖 Resumo Técnico

O **AWS Technical Essentials** é o curso de introdução técnica oficial da Amazon Web Services, projetado para profissionais que estão começando sua jornada na nuvem AWS. O curso fornece uma fundação sólida em conceitos técnicos essenciais, arquitetura de serviços e boas práticas da nuvem AWS.

### O que é abordado neste curso

Este curso introduz os conceitos fundamentais e a terminologia da AWS, navegação pelo **AWS Management Console**, e explora os principais serviços técnicos organizados nas seguintes áreas:

| Área | Serviços Principais |
|------|---------------------|
| **Computação** | Amazon EC2, AWS Lambda, Amazon ECS, Amazon EKS |
| **Rede** | Amazon VPC, rotas, grupos de segurança, ACLs |
| **Armazenamento** | Amazon S3, Amazon EBS, Amazon EC2 Instance Store |
| **Banco de Dados** | Amazon RDS, Amazon DynamoDB, bancos de dados purpose-built |
| **Segurança** | AWS IAM, políticas de segurança, compartilhamento de responsabilidade |
| **Monitoramento** | Amazon CloudWatch, otimização de custos |

### Objetivos de Aprendizagem

Ao finalizar este curso, você será capaz de:

- ✅ Descrever terminologia e conceitos relacionados aos serviços da AWS
- ✅ Navegar pelo AWS Management Console
- ✅ Articular os principais conceitos de segurança da AWS e do AWS Identity and Access Management (IAM)
- ✅ Distinguir entre diversos serviços de computação da AWS (EC2, Lambda, ECS, EKS)
- ✅ Compreender as ofertas de banco de dados e armazenamento da AWS (RDS, DynamoDB, S3)
- ✅ Explorar serviços de rede da AWS
- ✅ Acessar e configurar recursos de monitoramento do Amazon CloudWatch

### Estrutura do Curso

O curso é composto por **7 módulos**, cada um contendo tópicos teóricos e **laboratórios práticos (Hands-On Labs)** para fixação do conteúdo:

| Módulo | Título | Tópicos | Laboratório |
|--------|--------|---------|-------------|
| 1 | Introduction to Amazon Web Services | Cloud, Security, Employee Directory App | IAM Lab |
| 2 | AWS Compute | EC2, Lambda, Containers, Serverless | Launch App on EC2 |
| 3 | AWS Networking | VPC, Routing, Security | Create VPC & Relaunch App |
| 4 | AWS Storage | S3, EBS, Instance Store | Create S3 Bucket |
| 5 | Databases | RDS, DynamoDB, Purpose-built | Implement & Manage DynamoDB |
| 6 | Monitoring, Optimization, and Serverless | CloudWatch, Optimization, Serverless | Configure High Availability |
| 7 | Course Summary | Revisão geral | — |
