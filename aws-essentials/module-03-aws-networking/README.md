# 📘 Módulo 3: AWS Networking

## 📖 Resumo

Este módulo aborda os conceitos de rede na AWS, incluindo Amazon VPC (componentes, rotas, segurança), grupos de segurança, network ACLs, VPC Flow Logs e como criar uma VPC para relançar a aplicação Employee Directory.
