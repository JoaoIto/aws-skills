# 📘 Módulo 4: AWS Storage

> **Módulo 4 | AWS Technical Essentials | Nível: Fundamental**

## 📖 Resumo

Este módulo explora os serviços de armazenamento da AWS, incluindo Amazon S3 (tipos de armazenamento, classes de ciclo de vida), Amazon EBS (tipos de volume, snapshots), EC2 Instance Store e como escolher o serviço de armazenamento certo para cada caso de uso.
