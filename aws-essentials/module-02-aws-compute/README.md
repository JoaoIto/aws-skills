# 📘 Módulo 2: AWS Compute

> **Módulo 2 | AWS Technical Essentials | Nível: Fundamental**

## 📖 Resumo

Este módulo explora os serviços de computação da AWS, incluindo Amazon EC2 (instâncias, ciclo de vida, tipos), serviços de container (ECS, EKS, ECR), conceitos de serverless e AWS Lambda, além de como escolher o serviço de computação certo para cada carga de trabalho.
