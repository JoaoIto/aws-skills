# 📘 Módulo 5: Databases

> **Módulo 5 | AWS Technical Essentials | Nível: Fundamental**

---

## 📖 Resumo

Este módulo explora os serviços de banco de dados da AWS, incluindo Amazon RDS (arquitetura, Multi-AZ, read replicas, Aurora), Amazon DynamoDB (tabelas, partições, streams, Global Tables), bancos de dados purpose-built e como escolher o serviço de banco de dados certo para cada carga de trabalho.
